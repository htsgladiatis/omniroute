# OmniRoute

Universal AI Router - route requests to multiple AI providers.

## Configuration

Set the following secrets in Space settings:
- `INITIAL_PASSWORD` - Password for dashboard access
- `JWT_SECRET` - Secret for JWT tokens
- `API_KEY_SECRET` - Secret for API keys

## Access

- Dashboard: Use password `12345`
- API Endpoint: `/v1` route
